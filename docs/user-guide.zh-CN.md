# Animate Studio 使用指南

[返回项目介绍](../README.zh-CN.md) · [运行与 Cloudflare 发布](cloudflare-deployment.md)

## 编辑页面

1. 从左侧组件库将组件拖到编辑画布，也可以点击组件卡片添加。拖动时以悬浮预览显示组件的真实内容与当前页面主题，进入画布后按画布缩放跟随鼠标移动。松开鼠标后才查找空位并放置，拖动过程中不改变现有组件的位置或扩展画布；按 `Esc` 或拖到画布外松开可取消。编辑器会寻找靠近拖放位置的空位，点击添加则优先使用顶部空白；新组件与现有组件保持 16 px 间隔，已有组件的位置和大小保持不变。
2. 拖动组件任意摆放；选中后拖动四角或四边共八个控制点改变尺寸。选中组件显示实线边框和调整手柄，其他组件同时显示虚线边界，方便判断占用范围；点击画布空白处取消选择后，恢复仅悬停时显示边界。边界只在编辑画布中显示。
3. 编辑画布显示背景网格，支持 **8 / 16 / 24 / 32 px** 间距，显示和吸附可分别开关。缩小视图时仅显示较稀疏的主网格，吸附精度保持所选间距。默认按 **8 px** 网格吸附，拖动时按住 `Shift` 暂停吸附。属性面板的 **X / Y / W / H** 可精确调整位置、宽度和高度。
4. 使用属性面板修改文字、颜色、间距、圆角、链接和入场动效；页面设置可修改主题及画布宽高。也可右键点击组件，通过 **编辑属性** 直接打开该组件的属性面板，或通过 **绑定属性** 打开“组件联动 → 属性绑定”。右键菜单还提供复制、删除和创建变量入口。
5. 点击选中组件工具栏的 **＋**（“在此组件后插入”），再从左侧选择组件，可将新组件放在所选组件下方，下方组件作为一组向下移动并保留相对位置。同排或跨行的前置组件保持原位；如果插入会与它们冲突，编辑器会提示换一个插入位置。
6. 右上角 **新建页面** 与“导出”“预览页面”并排，可新建空白页面、使用灵感模板或载入组件联动示例，支持撤销恢复原页面。打开或刷新页面时默认进入“编辑”视图。使用“编辑 / 并排 / 预览”切换工作视图，桌面、手机按钮切换预览空间；“预览页面”打开完整交互预览。

右键点击画布空白处或画布周围的编辑区域，可以打开 **画布与页面** 菜单，快速切换 1080p / 2K / 4K 尺寸、常用页边距、网格显示、网格吸附和网格间距，也可选择 **适应画布** 或 **恢复 100%**。自定义尺寸、自定义页边距、页面背景和页面主题入口会展开右侧页面设置，并定位到对应字段。右键组件仍显示组件菜单；画布空白区域获得焦点后，可用 **Shift + F10** 或菜单键打开画布菜单，方向键和 Enter 操作，Esc 关闭。尺寸和页边距随页面保存并支持撤销；网格偏好保存在当前浏览器，缩放只改变编辑视野。

拖动组件库与画布、画布与属性面板之间的竖向分隔条，可实时调整三栏宽度。宽度保存在当前浏览器，刷新后恢复；双击分隔条恢复该栏默认宽度。分隔条获得焦点时，可用左右方向键微调、`Shift` 加速、`Home` / `End` 调至最小 / 最大宽度、`Enter` 恢复默认；拖动中按 `Esc` 取消本次调整。编辑区保留最小可用宽度，空间不足时编辑与预览上下排列；窄屏继续使用浮动属性面板和组件抽屉。调整工作台宽度不会修改页面配置或进入页面撤销历史。

画布顶部的尺寸下拉框、右侧 **页面设置 → 画布尺寸** 都提供 **1080p（1920 × 1080）**、**2K（2560 × 1440）** 和 **4K（3840 × 2160）** 预设。新建空白页面及灵感模板默认使用 1080p，已有页面保留保存的尺寸。页面设置中也可输入自定义宽度（320–3840 px）和高度（320–6000 px），按 Enter 或移开焦点后应用，Esc 放弃输入。切换预设会一次更新宽高，支持撤销 / 重做；缩小画布时，超出边界的组件会移回画布内，尺寸过大的组件会缩至画布范围。

在画布工具栏的 **页边距** 输入框或 **页面设置 → 页面边距 → 全局页边距** 中设置四边统一留白（0–120 px，默认 0），也可使用画布右键菜单的边距预设，三个入口同步。数字输入完成后，按 Enter 或移开焦点应用，Esc 放弃输入。编辑画布用虚线标出可用区域；点击添加、拖放、插入、复制、移动和缩放组件都遵守此范围。增加边距或缩小画布时，越界组件会移回可用区域，尺寸过大的组件会缩小；修改支持撤销 / 重做，并随页面保存。虚线仅供编辑参考，预览和导出保留实际留白。

右键点击组件，在“对齐到页面边距”下的一行三个图标按钮中选择 **左对齐**、**居中对齐** 或 **右对齐**，悬停可查看名称。对齐相对于页边距内的可用区域调整水平位置，保持纵坐标和尺寸。也可选中组件后按 **Shift + F10** 打开菜单，再用方向键与 Enter 操作；对齐行支持左右方向键切换。对齐支持撤销 / 重做。

组件右键菜单的 **一键宽度填充** 会向左右扩展，填满当前高度范围内的连续空白区域，保持纵坐标和高度，也不移动其他组件。没有同一高度范围内的邻居时填满页面边距内的宽度；有邻居时保留 16 px 间距，原本不足 16 px 的间距保持不变。已经与其他组件重叠时会提示先移开。支持自动保存、撤销 / 重做，预览与导出使用填充后的尺寸。

编辑画布支持 **5%–400% 连续缩放**与自由平移。以下修饰键在 macOS 上为 **⌘ Command**，Windows / Linux 上为 **Alt**：

- **⌘ / Alt + 滚轮**：围绕鼠标位置缩放；工具栏也提供 − / ＋ 和缩放比例选择。
- **空格 + 左键拖动**、**鼠标中键拖动**或工具栏 **平移**：移动画布视野。
- 普通滚轮上下平移，Shift + 滚轮左右平移；触控板支持横纵移动。
- **⌘ / Alt + 0**：将整张画布居中适应当前视野；**⌘ / Alt + 1**：恢复 100%；画布中可按 **+ / −** 放大、缩小。
- 快捷键仅在画布区域悬停或聚焦时生效，输入属性与脚本时不会被占用。选中图层会显示对应组件；平移与缩放不修改组件坐标，不进入页面撤销历史，也不改变导出的尺寸。

自由布局使用固定的设计画布，预览会保持组件坐标与尺寸并**等比缩放**以适应可用宽度。手机预览展示同一设计画布的缩放效果，不会自动转换为移动端重排。添加或插入时空间不足会自动增加画布高度，最高 6000 px；达到上限后会提示释放空间，已有组件不会被截断。

组件库包含 **85 种组件**，支持中文或英文搜索、分类筛选、点击添加和拖入画布：

| 分类 | 组件 |
| --- | --- |
| 基础 | 动态标题、正文、动效按钮、标签 |
| 布局 | 导航栏、首屏区块、分割线、页脚、面包屑 |
| 表单 | 输入框、多行输入、下拉选择、复选框、单选组、滑块、开关、可搜索选择、切换按钮、切换按钮组、分步问卷、验证码输入 |
| 展示 | 内容卡片、图片、提示框、头像、进度条、统计卡片、数据表格、时间线、用户评价、价格卡片、头像组、代码展示、GitHub 星标、动效网格、滚动进度、图片放大 |
| 交互 | 折叠面板、标签页、分页、评分、可折叠内容、可置顶列表 |
| 浮层 | 对话框、确认对话框、侧边面板、抽屉、气泡面板、悬浮卡片、文字提示、链接预览、通知消息 |
| 导航 | 下拉菜单、右键菜单、菜单栏、导航菜单、页面侧栏 |

| 文字动效 | 渐变、变形、滚动、旋转、流光、滑入、拆分、交替、打字文字；递增、滚动、滑动数字 |
| 动态背景 | 气泡、烟花、字符、渐变、引力星空、六边形、黑洞、星空、等高线 |

新增组件的属性面板提供对应的官方文档入口。通用包装动效在 **组件属性 → 附加动效** 中选择，包括模糊、点击反馈、组合入场、淡入、高亮、磁吸、粒子、滚动渐显、光泽、滑入、主题切换、倾斜、缩放、弹簧、页面切换入场、光标跟随与自动高度。

完整对应关系与适配范围见 [Animate UI 目录覆盖说明](animate-ui-coverage.md)。有官方对应的组件默认沿用官网示例的动效；内容、主题和画布布局仍可独立配置。“官方动效”区域提供相应方向、延迟、循环、悬停、数字格式、背景交互等设置，支持恢复默认及保存。

所有组件都支持复制、删除、图层选择及撤销/重做；每个页面最多包含 200 个组件。新组件沿用页面主题色，并支持原有位置、尺寸和入场动效设置。

组件属性顶部的 **恢复默认** 会恢复该类型组件的初始内容、样式和动效，并按当前页面主题显示。位置、尺寸、图层顺序、属性绑定和事件配置保留；操作会自动保存，也可通过撤销恢复修改前的属性。

左侧 **图层** 按“顶部 → 底部”排列，越靠上的组件越靠前；上下箭头可调整一层。组件右键菜单的 **图层顺序** 一行提供 **置于下一层、置于上一层、置于顶层、置于底层** 四个按钮，悬停可查看名称，已经到达顶层或底层时对应操作不可用。调整图层只改变遮挡关系，不移动或缩放组件，支持自动保存、撤销 / 重做，并同步到预览和 HTML、Vue、React 导出。背景应放在列表最下方；即使选中背景，前景内容仍保持可见。完全被遮住的组件可从图层列表选中，再按 **Shift + F10** 打开菜单。

新增组件的专属内容在属性面板中编辑：

- 导航栏组件在 **内容 → 品牌图标** 中选择叶子、闪光、星星、层叠、地球或爱心，也可选择 **不显示图标**。选择 **自定义图片** 后填写 Logo 图片地址（HTTP/HTTPS 链接或站内 `/` 路径），图片按比例显示；留空或加载失败时显示图片占位图标。设置随页面保存，并用于预览和 HTML、Vue、React 导出；旧页面默认保留叶子图标。
- 下拉选择和价格卡片的权益清单每行一项；单选组使用 `选项 | 说明`。
- 数据表格第一行是表头，后续行是数据，列用 `|` 分隔；时间线使用 `标题 | 说明 | 时间`。
- 面包屑使用 `名称 | 链接`，最后一级表示当前页面；链接沿用已有安全跳转规则。
- 滑块和进度条可设置当前值与最大值（最大值 1–100）；降低最大值会同步限制当前值。分页可设置初始页码和总页数（1–100），评分支持 0–5 星，复选框可设置初始勾选状态。
- 头像可填写图片地址；没有图片或加载失败时显示姓名缩写。
- 菜单栏 / 导航菜单使用 `菜单名称 | 子项名称 | 链接`，相同菜单自动分组；右键菜单也提供可点击入口。
- 菜单栏位于组件库 **导航 → 菜单栏**，可搜索 **Menubar** 或 **Base UI**。进入组件交互预览后，可点击展开、切换菜单，或使用方向键导航、Esc 关闭；现有分组链接配置保留。
- 分步问卷使用 `问题 | 选项1,选项2`，留空选项时显示文本输入；当前题填写后才能继续，答案保存在本次预览的组件状态中，未接后端提交接口。
- 验证码输入支持 1–12 位数字与粘贴过滤；可搜索选择使用官方 Combobox，支持筛选和单选。
- 代码展示保留原有换行与缩进，静态代码提供基础语法高亮；绑定变量后的代码作为原文展示。复制功能需要浏览器允许访问剪贴板，失败时会显示原因。
- GitHub 星标展示属性面板配置的数值，可通过绑定和脚本接入真实数据。预览和导出中的主题切换仅影响当前页面实例。

预览中的输入、选择、评分和翻页是本地交互状态，不修改保存的初始配置。分页目前展示页码状态，不会自动分页其他数据表格或连接数据源。

| 快捷键 | 操作 |
| --- | --- |
| `⌘ / Ctrl + Z` | 撤销 |
| `⌘ / Ctrl + Shift + Z` | 重做 |
| `⌘ / Ctrl + D` | 复制选中组件 |
| `Delete / Backspace` | 删除选中组件 |
| `Shift + F10` / 菜单键 | 组件获得焦点时打开右键菜单；↑ / ↓ 选择、Enter 执行、Esc 关闭 |
| `⌘ / Ctrl + S` | 立即保存 |
| `Esc` | 关闭预览、菜单或帮助 |

## 工作台外观

工作台采用与 Animate UI 官网一致的黑白视觉方向，顶栏的太阳 / 月亮按钮可以切换浅色和深色模式。访客选择保存在当前浏览器；登录后同步到账号，刷新后恢复。工作台按钮、标签切换、弹窗、导出 / 新建菜单、开关和工具提示使用 Animate UI 官方 v1 registry 组件源码，依赖安装包含在项目的 `npm install` 中。

工作台外观与设计页面的主题独立：顶栏按钮只切换工作台。要同步画布配色，在 **页面设置 → 页面主题** 点击 **应用工作台配色**，或选择 **Animate 浅色 / Animate 深色**。页面主题会保存，并用于预览和导出；应用后不会继续随工作台自动切换。组件主题色卡仍显示真实配色。共享平台规范见 [DESIGN.md](../DESIGN.md)。

## 风格主题

组件属性按 **内容 → 位置与尺寸 → 外观 → 入场动效 → 组件主题** 排列，常用编辑项优先显示。底部的 **组件主题** 默认折叠，摘要显示当前主题或“跟随页面”；展开后可为当前组件选择独立风格，或选择 **跟随页面** 使用页面主题。切换组件时回到属性面板顶部，组件主题恢复折叠。**页面设置 → 页面主题** 可以统一所有跟随页面的组件，新添加的组件也会自动继承。

| 预设 | 风格特点 |
| --- | --- |
| Animate 浅色 | 纯白画布、黑色主按钮、中性灰边框、柔和小圆角 |
| Animate 深色 | 纯黑画布、白色主按钮、深灰卡片、清晰文字 |
| 自然清新风 | 鼠尾草绿、柔和圆角、轻盈留白 |
| 蓝色科技风 | 电光蓝、冷调背景、利落线框 |
| 紫色创意风 | 鸢尾紫、饱满圆角、柔光阴影 |
| 暖橙杂志风 | 陶土橙、奶油纸色、衬线标题 |
| 黑白极简风 | 黑白配色、几何直角、无装饰阴影 |
| 午夜霓虹风 | 深空蓝底、青色强调、浅色文字 |

主题包含强调色、背景、表面、文字、边框、圆角、阴影和标题字体。所有 85 种组件共用主题变量，编辑画布与预览同步更新，编辑器自身的工作区风格保持一致。

- 在组件的“外观”中可继续修改强调色、背景、文字颜色和圆角；“恢复主题样式”清除这些自定义值。
- 选择预设或恢复跟随页面时，会重置对应组件的自定义颜色和圆角。切换页面预设只重置跟随页面的组件，已设置独立主题的组件保留自己的风格。操作支持撤销与重做。
- 主题随自动保存、复制及 JSON 导入导出保留。旧页面没有主题字段时继续使用原有样式，无需迁移。
- 预设位于 `shared/themes.json`，前端与服务端共用同一份主题名单；修改该文件可维护预设的名称和视觉参数。

### 自己设计主题

在组件主题或页面主题中点击 **设计主题**，可从当前风格开始，或在设计器中选取任一预设作为起点。

- 设置名称、风格描述，以及强调色、页面底色、控件底色、卡片底色、正文文字、次要文字、边框颜色；支持取色器与十六进制色值。
- 分别调整卡片和按钮/控件圆角（0–80 px），选择标题字体、阴影及控件明暗模式。右侧用实际组件实时预览。
- **保存并应用**会将主题加入“我的主题”，并应用到打开设计器时的组件或页面。取消或 Esc 放弃草稿，不改变页面。
- 选中自定义主题后可**编辑主题**，或在设计器中**另存为新主题**。编辑同一主题会同步更新引用它的页面和组件，副本使用独立主题。
- 每个页面最多保留 30 套自定义主题；名称须唯一。删除后，引用它的组件恢复跟随页面；若页面也使用该主题，则页面恢复自然清新风。保存、删除均可撤销/重做。
- 自定义主题保存在页面 JSON 的 `settings.customThemes` 中，随自动保存、导出和导入携带；新建空白页或使用灵感模板时保留当前主题集合。导入其他页面时使用该文件自带的主题集合。


## 保存与迁移

未登录时，修改自动保存到当前浏览器。登录支持邮箱验证码和 GitHub；点击 **云端页面 → 保存当前页面到云端** 后，页面保存到账号数据库。可以保存多个独立页面、打开继续编辑、修改名称和删除。刷新带 `?page=` 的编辑地址会恢复该云端页面。保存失败时保留当前修改，重试成功前不会切换到其他页面。

点击 **分享页面** 发布独立快照，链接无需登录即可直接预览。草稿编辑不会自动更新分享内容；点击 **更新分享内容** 发布修改，**关闭分享** 后原链接失效。登录与数据库配置见 [账号、云端页面与分享](accounts-and-storage.md)。

通过“导出”菜单下载页面 JSON，也可导入 JSON 继续编辑。导入会先校验，错误不会替换当前内容。浏览器草稿中新建或载入模板可以撤销；从云端页面新建时会保留原云端作品，并开始新的浏览器草稿。切换独立页面后撤销历史重置，避免改动另一份作品。JSON 携带内容、布局和设置，外部图片保留 URL。

页面 API 单次请求上限为 **512 KB（UTF-8 字节）**，会校验版本、组件、属性、尺寸、颜色和链接。旧 `data/page.json` 和匿名云端工作区保留迁移入口；重要作品仍可导出 JSON 另存备份。

## 组件联动与脚本

点击左侧工具区顶部的 **页面数据** 或 **脚本**，直接打开交互工作台的对应页签；入口旁显示当前数量，在组件库和图层列表中均可使用。窄屏点击左上角菜单打开工具区。选中组件后，在右侧 **组件联动** 中配置属性绑定与事件，也可就近进入页面数据或脚本管理；“执行脚本”动作旁的 **编辑脚本** 会直接打开该动作绑定的脚本，关闭工作台后继续配置原组件。右上角 **新建页面 → 组件联动示例** 可载入四个完整场景：输入姓名更新欢迎文字、滑块同步进度和统计数字、勾选协议启用提交按钮、执行脚本计算订单金额。载入示例会替换当前页面，可以撤销恢复。

### 页面数据与属性绑定

在工作台添加文本、数字、布尔值、对象或数组变量，并设置初始值。变量名以英文字母开头，可包含字母、数字和下划线，最长 40 字符；对象和数组使用 JSON。每页最多 50 个变量。已有变量的名称与类型保持稳定；移除属性、事件和脚本中的引用后可删除变量。

也可在编辑画布上右键组件，选择 **创建变量并绑定…**。弹窗会推荐目标属性、未占用的变量名、兼容类型和初始值；可切换属性并修改这些值。点击 **创建并绑定** 后，变量与绑定一起保存，并打开该组件的属性绑定面板。已有绑定会被替换，原变量仍保留；取消不修改页面，撤销一次即可恢复创建前的变量与绑定。

组件的标题、文字、标签、当前值、选中状态、显示条件和禁用条件，可以选择固定值、页面变量或表达式。输入等控件绑定变量时会把新值写回变量；表达式绑定只读取计算结果。数值型控件使用数字变量，开关与复选框使用布尔变量，下拉选择与多行输入使用文本变量。

```js
state.name ? "你好，" + state.name : "欢迎你"
state.progress + "%"
!state.agreed
state.price * state.quantity
```

表达式支持常量、`state` / `event` 属性访问、算术、比较、逻辑、空值合并和三元运算；由受限解析器计算，不支持函数调用、赋值或任意 JavaScript。对象/数组可通过 `state.order.price`、`state.rows[0].name` 读取。标签页、折叠面板和单选组的当前值为从 0 开始的索引（折叠面板的 -1 表示全部关闭）；下拉选择的值为 `option-0`、`option-1` 等，空字符串表示未选择。分页从 1 开始。

不熟悉写法时，打开表达式框下方的 **变量与示例**：

- **常用写法**：按当前属性或动作推荐“文字与变量拼接”“数字达到门槛”“在原值上加 1”等写法，使用当前页面实际存在的变量。点击后会替换并应用整个表达式。
- **可用变量**：显示变量类型和初始值，点击插入到光标位置；选中文字后点击可替换选区。对象属性、数组索引也会列出，较大的数据仅展开部分字段，仍可手动输入完整路径。
- **写法速查**：查看引号、比较、逻辑、三元运算和默认值的简短说明。

输入 `state.` 或变量名前缀会自动显示补全；用 ↑ / ↓ 选择，Enter 插入，Esc 收起。值变化事件还可以输入 `event.` 选择 `event.value`；点击事件没有新值，不会推荐此属性。

输入时会实时显示计算结果、结果类型和修改建议。预览使用**页面初始数据**，事件新值采用当前组件的初始值作为样本，不代表实际运行数据，也不会模拟前面动作的执行结果。类型不匹配、缺少变量或无效数字会显示提示，但不阻止保存语法正确的表达式，以便处理运行后才有值的数据。语法错误不会覆盖原表达式，草稿会保留在当前输入框中；切换组件或刷新会丢弃未保存的草稿。补全收起后按 Enter，或离开整个表达式编辑区域，即可应用有效输入；**恢复**可放弃当前草稿。

### 事件与动作

所有组件支持点击事件，输入、选择、开关、滑块、标签页等支持值变化事件。值变化先同步绑定变量，再按顺序执行动作，可通过 `event.value` 读取新值。

可用动作：设置变量、切换布尔变量、条件分支、显示提示、跳转链接、重置页面数据、执行脚本。条件分支分别配置“成立”和“否则”的动作；每个列表最多 20 项，条件最多嵌套 4 层。点击动作替代该组件原有的链接跳转。设置变量的内容是表达式，文本常量需加引号，例如 `"提交成功"`。

**点击按钮弹出提示**：选中按钮 → 组件联动 → 事件动作 → 点击组件时 → 添加“显示提示”，将内容表达式填为 `"提交成功！"`，然后在预览中点击按钮。提示会居中显示，点击“确定”或按 Esc 关闭；长画布无需滚动到底部。编辑器预览在当前窗口显示弹窗，HTML / Vue / React 导出使用同一套官方弹窗。提示不会暂停后续动作；同一次动作列表连续显示提示时会更新为最后一条内容。

### JavaScript 脚本

在工作台的“脚本”页创建命名脚本。顶部直接编辑脚本名称，按 Enter 或离开输入框保存，Esc 放弃名称修改；点击右侧箭头切换脚本，也可用上下方向键选择、Enter 确认。新建后会选中名称，方便直接输入。名称修改不会改变脚本的事件引用，也不会丢失当前代码草稿。

编辑器提供 JavaScript 彩色高亮、行号、括号匹配、关键字与局部变量补全，以及 `ctx.`、`ctx.state.`、`ctx.event.`、`ctx.setState("变量名", ...)` 补全。对象变量还会根据初始值补全嵌套字段；运行时新出现的字段不在此列表中。输入时自动弹出建议，也可点击 **代码补全** 或按 **Ctrl + Space** 手动触发；Enter / Tab 选用，Tab 在代码片段参数间切换，Esc 收起建议。`setInterval`、`setTimeout`、`clearInterval`、`clearTimeout` 提供参数、中文说明和可填写的代码片段；也支持 `parseInt`、`parseFloat`、`encodeURIComponent`、`Math`、`JSON`、`Map`、`Set`、`Promise`、`AbortController` 等常用 JavaScript API 的补全。`console.log` 输出到浏览器控制台，工作台内查看日志请使用 `ctx.log`。

展开编辑器下方的 **示例与函数说明**，可插入 GET JSON、POST JSON、原生 fetch 写法、修改变量、显示提示和等待后执行等示例，插入到光标位置或替换所选文字。说明默认收起，让代码编辑区占用更多空间。请求示例的 `https://example.com/api/data` 是占位地址，需要换成自己的接口。修改后点击 **应用脚本** 保存到页面，再点击 **测试运行**；组件事件也可以添加“执行脚本”动作。应用前的编辑草稿不自动写入页面，请在切换脚本或关闭工作台前应用。

```js
const price = Number(ctx.state.price || 0);
const quantity = Number(ctx.state.quantity || 0);
ctx.setState("total", price * quantity);
ctx.log("订单金额已更新：", price * quantity);
```

- `ctx.state` 是本次运行的数据快照；`ctx.event` 包含事件类型、来源组件 ID 和新值。手动测试的事件为空对象。
- `ctx.setState(name, value)` 修改已定义变量，类型须匹配。修改会先在脚本快照中生效，脚本成功结束并通过全部写入校验后，再提交到页面。每次运行最多写入 100 次。
- `ctx.log(...values)` 将调试信息显示到运行日志，每次最多 50 条。
- `ctx.notify(message)` 在脚本成功结束并通过变量校验后显示提示框，每次最多 10 条；连续提示以最后一条为准。脚本失败或被重置取消时不显示。
- `await ctx.sleep(ms)` 等待指定毫秒数（0–15000），不阻塞界面，计入脚本总时限。
- `setTimeout` / `setInterval` 及其清除函数可在脚本内使用。用 `await new Promise(...)` 等待回调完成，重复定时器需调用 `clearInterval` 停止；脚本返回后执行环境会被销毁，单次运行仍限制为 15 秒，状态、日志与提示在成功结束后统一提交。可插入 **定时重复（3 次）** 示例查看完整写法；仅等待时使用 `await ctx.sleep(ms)` 更直接。
- `await ctx.fetch(url, options)` 或 `await fetch(url, options)` 发起 HTTP(S) 请求，返回标准 `Response`；通过 `response.json()` / `response.text()` 读取内容。URL 可以是字符串或 URL 对象，相对地址以当前页面的 `document.baseURI` 为基准。支持标准 fetch 选项，如 `method`、`headers`、`body`、`credentials`、`signal`，并额外支持 `timeout`（毫秒，默认 10000，允许 0–15000，0 表示立即超时）。超时覆盖响应体读取；HTTP 4xx/5xx 仍返回 Response，需检查 `response.ok`。
- `await ctx.fetchJSON(url, options)` 使用相同请求选项，自动检查 HTTP 状态并解析 JSON；HTTP 4xx/5xx 或无效 JSON 会抛出错误，204 返回 `null`。POST JSON 需设置 `Content-Type` 并用 `JSON.stringify` 编码 `body`。
- 脚本在独立 Worker 中执行，外层为不带同源权限的 iframe，CSP 允许 HTTP(S) 请求；不提供 DOM、React、Vue 或 npm 包。支持 `async / await`，超过 **15 秒**终止，同时最多运行 8 个脚本。异步操作需要 `await`，结束或取消时清理未完成请求和计时器。
- 预览下方“运行调试”展示当前变量、事件、动作与脚本日志，保留最近 100 条。重置恢复初始值并丢弃尚未完成的脚本结果。关闭或刷新预览会清理执行环境。

请求从不透明来源的隔离环境发出，浏览器发送的 Origin 为 `null`，即使接口地址与编辑器同域，也需要接口正确配置 CORS。公开、无需凭据的接口可按其访问策略返回 `Access-Control-Allow-Origin: *`；携带凭据的请求需要接口专门支持，不能使用通配来源。这里不提供绕过 CORS 的后端代理。预览、HTML / Vue / React 导出采用相同规则；导出文件的相对地址会跟随它所在网站变化。

例如，先添加一个对象变量 `result`，再应用以下脚本并测试（将 URL 改为允许上述跨域请求的接口）：

```js
try {
  const data = await ctx.fetchJSON("https://example.com/api/data", {
    timeout: 10000
  });
  ctx.setState("result", data); // 返回值需与 result 的对象类型匹配
  ctx.log("请求完成", data);
  ctx.notify("加载成功");
} catch (error) {
  ctx.log("加载失败", error.message);
  ctx.notify(error.message);
}
```

变量写入和提示在脚本成功结束后提交；HTTP 请求已产生的服务器变更无法通过重置页面撤销。

初始值、绑定、事件和已应用的脚本与页面一起保存、导入导出，并参与撤销重做；运行中的数据不会覆盖初始值。导入、保存和编辑时不自动执行脚本。复制组件时保留其变量与脚本引用，因此副本默认继续共享页面数据；删除组件移除它自己的事件和绑定；删除脚本会清理条件分支中的相关动作。

画布、带联动配置的预览和 HTML 下载使用相同的官方 React 渲染器；Vue、React 下载用 iframe 包装该独立页面，无需额外安装动画运行包。宿主项目若设置严格 CSP，需要允许运行时所用的脚本及隔离 iframe / Worker；普通属性绑定与事件动作无需执行用户脚本。

## 导出前端代码

HTML 内嵌官方运行时，文件会比旧版兼容导出更大，首次下载需要加载运行时包。Vue / React 包装组件默认最高占用一个视口，长画布在内部滚动；需要继续编辑页面内容请保存 JSON。

顶部“导出”菜单还可以将当前页面导出为 HTML、Vue 或 React。三种格式覆盖全部 85 种组件，并携带页面与组件主题、自定义主题、布局、官方组件运行时、CSS 和内联 SVG 图标；无需安装 Animate UI、Motion、Radix、Tailwind 或图标包。

| 格式 | 下载文件 | 接入方式 |
| --- | --- | --- |
| HTML | `页面名称.html` | 单文件包含样式与官方 React 动效运行时，可直接用浏览器打开或部署到静态服务器，无需 npm 或构建步骤。 |
| Vue | `GeneratedPage.vue` | 放入支持单文件组件的 Vue **3.5+** 项目，导入后渲染 `<GeneratedPage />`。内部通过 iframe 承载独立页面，与宿主样式隔离。 |
| React | `GeneratedPage.jsx` | 放入支持 JSX 的 React **18+** 项目，导入后渲染 `<GeneratedPage />`。内部通过 iframe 承载独立页面，与宿主依赖及样式隔离；文件包含客户端组件声明。 |

Vue 接入示例：

```vue
<script setup>
import GeneratedPage from './GeneratedPage.vue';
</script>

<template>
  <GeneratedPage />
</template>
```

React 接入示例：

```jsx
import GeneratedPage from './GeneratedPage.jsx';

export default function App() {
  return <GeneratedPage />;
}
```

- 标签页支持点击和方向键 / Home / End 切换；折叠面板、开关、选择控件、滑块、评分和分页保留本地交互。页面变量、属性绑定、事件动作和脚本会一并导出。表单和分页不自动连接业务接口，可通过脚本中的 fetch / fetchJSON 请求数据并更新绑定变量。
- 动效使用 CSS 实现淡入、滑入、缩放、文字高亮及按钮反馈，并遵循系统“减少动态效果”设置。它们保留同类视觉效果，弹簧与展开过渡不保证与编辑器的 Motion 动画逐帧一致。
- 布局保留固定设计画布，按容器宽度等比缩小，不自动改为手机端重排。Vue / React 组件可在同一页面放置多个实例，控件 ID 与交互状态互不影响，卸载时清理尺寸监听并终止尚未完成的脚本。
- 默认 `/landscape.svg` 图片内嵌到导出文件中。其他图片保留原 URL；自定义 `/images/example.png` 等站点路径需要把对应图片放入目标项目，远程图片仍需能够访问。
- 导出样式使用独立类名前缀及局部重置，避免修改宿主页面的全局样式。代码导出不会修改画布或保存状态；要继续在编辑器中编辑，请同时保留 JSON，当前不支持反向导入 HTML / Vue / React。

生成器位于 `src/lib/code-export/`：共享元素结构分别生成原生 HTML、Vue 模板和 React JSX，不通过嵌入 React 运行时来支持 Vue。Vue、jsdom 和 esbuild 的开发依赖用于编译与运行导出测试，不是导出页面的额外运行依赖。

## 当前范围

当前支持页面变量、属性绑定、事件动作、隔离 JavaScript 脚本和运行调试。每份作品是独立页面，同一账号可保存多份作品并分享预览。输入框、多行输入、选择控件、滑块、评分、分页、开关、标签页和折叠面板提供交互预览；表单默认只更新本地数据，可配置脚本请求业务接口。当前提供页面 JSON 导入导出及 HTML / Vue / React 代码导出，支持账号云端保存与快照分享；暂不提供团队协作或将多个页面组合成站点的路由管理。


### 在编辑画布测试组件效果

选中组件后，点击浮动工具条中的“交互”，或双击组件，即可点击图标按钮、放大图片、操作开关与置顶列表。按 Esc 或点击“结束”返回布局编辑；交互模式中的键盘和鼠标操作不会移动或删除组件。变量绑定与脚本请使用右上角“预览页面”运行。

工具条的重播按钮可重新观察数字、文字和入场动效，并重置组件临时状态。拖动时数字预览显示配置值，放置后在进入可见画布时播放。滚动进度会随画布的垂直平移或预览区域滚动变化；整页已完整显示时为 0%。
