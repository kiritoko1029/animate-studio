# 自定义组件设计器

在左侧 **组件 → 我的组件** 中，用 HTML、CSS 和 JavaScript 创建可重复使用的组件。游客可以保存到本机；登录后可以显式保存到账号，发布独立的组件分享链接。

## 创建第一个组件

1. 点击 **新建组件**，或选择起步模板、计数按钮、信息卡片、实时时钟、链接按钮中的一个模板。
2. 输入组件名称，在三个代码面板中编写内容。HTML 是组件 body 的内容；CSS 只作用于该组件；JavaScript 在 HTML 加载后执行。
3. 点击 **运行**（`⌘ / Ctrl + Enter`），在预览中操作组件；控制台会显示日志、运行错误和代码行号。开启自动运行后，停止输入片刻会刷新预览。
4. 在 **设置** 中填写说明、默认尺寸和可编辑的实例字段。需要参考时打开右上角 **编写指南**。
5. 点击 **保存到本机**（`⌘ / Ctrl + S`），再点 **添加到页面**。也可以一次点击 **保存并添加到页面**。

设计器预览支持当前页面、浅色和深色主题。窄屏使用“代码 / 预览”标签切换。页面中插入的组件可以移动、缩放、复制、调整图层和撤销；双击可测试自身交互，“预览页面”可测试页面联动。

## 编写代码

HTML 面板中的示例：

```html
<button type="button" class="welcome">
  <span data-prop="label">点击我</span>
  <strong class="count">0</strong>
</button>
```

CSS 面板：

```css
body { display: grid; place-items: center; }
.welcome {
  padding: 12px 20px;
  border: 0;
  border-radius: var(--as-radius);
  background: var(--as-accent);
  color: var(--as-on-accent);
  cursor: pointer;
}
```

JavaScript 面板：

```js
let count = 0;
document.querySelector('.welcome').addEventListener('click', () => {
  document.querySelector('.count').textContent = String(++count);
  component.log('当前次数', count);
});
```

在“设置”中启用 **标签** 字段，`data-prop="label"` 就会跟随每个实例的标签值。计数器的局部状态在重新运行、刷新或重新打开预览后重置；它不会自动变成持久保存的页面变量。

| 接口或属性 | 用途 |
| --- | --- |
| `component.props` | 只读的实例字段：已启用的 `title`、`text`、`label`、`url`、`imageUrl` |
| `component.onProps(fn)` | 字段或主题变化时调用 `fn(props, theme)`，返回取消监听函数 |
| `component.theme` | 当前主题颜色、字体与圆角 |
| `component.log(...values)` | 向设计器控制台输出日志；也支持 `console.log / warn / error` |
| `component.openLink(url)` | 请求打开符合页面链接规则的链接 |
| `data-prop="title"` | 将元素文字与实例字段同步 |
| `data-prop-href="url"` | 将链接地址与实例字段同步 |
| `data-prop-src="imageUrl"` | 将图片地址与实例字段同步 |

CSS 可以使用 `--as-accent`、`--as-on-accent`、`--as-text`、`--as-muted`、`--as-surface`、`--as-panel`、`--as-canvas`、`--as-border`、`--as-radius`、`--as-font`。深色主题的根元素带有 `data-scheme="dark"`。建议用百分比、flex 或 grid 适应组件框的尺寸。

## 保存、恢复与版本

- 本机组件保存在当前浏览器；清除站点数据会移除它们。登录不会自动上传本机组件。
- 云端组件需要登录并点击 **保存到账号**。从本机复制到账号时，本机副本保留；后续编辑的是账号中的版本。
- 未保存的修改会暂存到浏览器，关闭前会提示保存或放弃。如果浏览器拒绝存储，界面会提示暂存失败，请先保存或保持窗口打开。
- 云端组件草稿按账号区分；切换账号会关闭原账号的设计器，未保存内容留给原账号恢复。本机组件和本机草稿属于当前浏览器。
- 恢复旧草稿仍保留它编辑时的版本号。如果另一处已保存新版本，会提示冲突，可取消、另存副本或明确覆盖。
- 保存请求期间的新修改会留在设计器中；“保存并添加到页面”插入的是这次成功保存的版本。

页面中的组件包含插入时的代码副本。编辑、删除、取消分享源组件不会破坏已有页面。属性面板出现新版本提示后，点击 **更新此实例** 才替换代码；仍保留的实例字段、位置、尺寸和外观会保留，已移除字段的绑定会清理。需要保留两版时，可以先复制实例。

## 分享组件

1. 把组件保存到账号，点击 **分享组件 → 创建分享链接**。
2. 访客通过 `/c/<分享标识>` 查看说明、预览和只读源码，并复制到自己的本机组件库；已登录的访客还可复制到自己的账号。
3. 发布后继续编辑不会改变访客看到的内容。点击 **更新分享内容** 发布当前保存版本。
4. **关闭分享** 或删除源组件会使原链接失效。访客已经复制的组件和页面中已插入的副本仍可使用。

分享会公开组件源码，因此不要在代码中写入密钥或私密数据。登录和数据库配置沿用 [账号与存储配置](accounts-and-storage.md)，无需额外的 AI 服务。

## 页面联动与导出

实例的标题、正文、标签可在 **组件联动** 中绑定页面变量，点击组件可触发页面的点击动作。组件代码不能直接读写页面变量；声明了页面点击动作时，它会优先于组件请求打开链接的行为。

JSON、HTML、React、Vue 导出均携带组件代码副本，使用相同的隔离渲染路径，不依赖源组件库或分享链接继续存在。外部图片、字体和媒体仍需要可访问的地址。导出的 Vue / React 文件是嵌入页面的包装组件，不会把编写的 HTML 转成 Vue / React 源组件。

## 支持范围与限制

- 每个组件的 HTML、CSS、JavaScript 各最多 30,000 字符；名称最多 60 字符，说明最多 300 字符。
- 默认尺寸：宽 40–1920 px、高 32–1600 px；本机库最多 200 个组件，每账号最多 100 个，每页最多 40 个自定义实例，并仍受页面总大小限制。
- 代码运行在独立沙箱内，无法访问编辑器 DOM、Cookie、localStorage 或其他组件文档。
- 不支持 `import`、npm 包、外部脚本、外部样式表、`eval`、表单提交和弹窗；HTML 中的 `<script>` 与 `onclick` 等内联事件不执行，请把逻辑写在 JavaScript 面板。
- `fetch`、XHR、WebSocket 等网络 API 被阻止；允许加载图片、媒体和字体资源。
- 设计器预览为循环添加超时保护；页面、分享和导出不注入此保护。启动超时会停止组件帧，提示后可重新运行。浏览器差异或极端脚本仍可能影响响应，应避免长时间同步运算。
