# 工作台国际化

顶部「更多（⋯）→ 语言 / Language」菜单切换工作台语言，无需刷新。首次访问时，浏览器首选语言为中文则使用简体中文，其他语言使用英文；有效的本地选择优先。偏好保存于 `localStorage` 的 `animate-studio:locale`，同源标签页同步更新。存储不可用时，仍可在当前会话切换。

语言偏好不写入 `PageDocument`、账号外观设置或云端页面。切换不会改动页面文字、用户命名、组件代码、布局、撤销历史或导出数据。内置样例与已经保存的作品内容不会自动翻译；外部文档仍使用原站点语言。

## 添加工作台文案

- `src/i18n/index.ts` 管理语言、插值和现有系统消息的翻译；`src/i18n/react.ts` 提供 React 订阅。浏览器入口在渲染前调用 `initializeLocale()`，`document.documentElement.lang` 同步更新。
- 使用中文源文案作为键：`t('页面名称')`，并在 `src/i18n/en.json` 中添加英文。动态内容使用完整句子与占位符，如 `t('已导入「{0}」', { 0: page.name })`。插值保持原样，不能对用户输入调用翻译函数。
- 分类、动作、页面属性和选项的存储值保持稳定，只在渲染标签时翻译。模块级常量保留原文，避免在模块初始化时固定语言。
- 组件内置名称使用 `src/i18n/catalog.ts` 的显示适配；自定义组件名称保持用户输入。预设主题名称可翻译，自定义主题名称不翻译。
- `translateMessage` 在界面边界处理旧 API 和校验模块返回的中文消息，保留原服务端契约；未知消息原样显示。新增校验消息需同步字典。共享渲染器和序列化脚本运行时不读取工作台语言。

运行 `node --test tests/i18n.test.mjs tests/account-editor.test.mjs` 验证语言解析、存储不可用、插值完整性、切换、刷新恢复、跨标签页同步和编辑数据保留。其他验证按实际改动范围选择。
